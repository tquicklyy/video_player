# «KubSTU Education Video Player»

## Общая информация
Это репозиторий ПО «KubSTU Education Video Player», предназначенного для повышения качества образования студентов через просмотр уроков по программированию.

Для установки программы необходимо:

1. Установить папку проекта из репозитория;
2. Запустить главный исполняемый файл приложения «Main».

## Возможности ПО

Рассмотрим возможности ПО и его структуру.

1. При открытии приложения пользователя встречает главное меню.

![Главное меню](/src/main/resources/images/main-menu.png)

2. При выборе верхней кнопки главного меню пользователь попадает в окно выбора темы и подтемы.

![Темы и подтемы](/src/main/resources/images/theme-subtopic-menu.png)

Выбрав необходимые пункты выпадающих списков, пользователь получает перечень доступных уроков.

![Урок](/src/main/resources/images/lesson.png)

В программном средстве нет заранее загруженных материалов. Всё загружает сам пользователь через меню загрузки. Доступен онлайн-просмотр видео как перед загрузкой, так и во время неё.

![Загрузка урока](/src/main/resources/images/download-lesson.png)

Пользователь может скачивать сразу несколько видео одновременно, переключаясь между ними через вкладку с карточками видео.

![Параллельная загрузка. Урок 1](/src/main/resources/images/parallel-download-first-lesson.png)
![Параллельная загрузка. Урок 2](/src/main/resources/images/parallel-download-second-lesson.png)

После загрузки видео пользователь также может удалить учебный материал с помощью кнопки удаления. Если она серая, то видео отсутствует на устройстве.

Пользователь может получить дополнительную информацию по кнопке левее кнопки удаления видео (данная кнопка есть и в меню загрузки в правом верхнем углу).

![Информация об уроке](/src/main/resources/images/info-about-lesson.png)

Если у пользователя отсутствует подключение к интернету, он может перейти в автономный режим по специальной кнопке в правом верхнем углу и просматривать локальный материал, находящийся на ПК.

![Автономный режим](/src/main/resources/images/offline-mode.png)

Пользователь может просматривать видеоуроки в удобном окне просмотра.

![Окно просмотра уроков](/src/main/resources/images/lesson-watch-window.png)

3. При выборе средней кнопки главного меню пользователь попадает в окно просмотра собственных материалов.

![Окно просмотра собственных видео](/src/main/resources/images/own-video-watch-window.png)

4. При выборе нижней кнопки главного меню пользователь попадает в окно просмотра информации о ПО.

![Окно просмотра информации о программе](/src/main/resources/images/info-about-program-window.png)
